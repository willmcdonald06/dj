# Test data

Generated signals only (tones, click tracks, synthetic kicks); no copyrighted music.
`tools/gen-test-data.sh` regenerates the audio files and documents what each contains.

- Decoder tests (Milestone 1): `tone-*` files in FLAC, MP3, M4A (AAC) and WAV.
- Golden tests for onset detection and waveform summaries arrive in Milestone 3.
